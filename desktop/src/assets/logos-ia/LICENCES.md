# Logos des éditeurs d'IA

Ces logos désignent le service de chaque éditeur dans l'écran « Vos connexions » ;
ils restent la marque de leur éditeur.

- Fichiers sans préfixe : `@lobehub/icons-static-svg` 1.95.1, licence MIT,
  © LobeHub (https://github.com/lobehub/lobe-icons).
- Fichiers `si-*.svg` : `simple-icons` 16, licence CC0-1.0
  (https://github.com/simple-icons/simple-icons).

Un éditeur sans logo dans ces deux jeux est affiché par ses initiales : un logo
redessiné à la main serait une contrefaçon de sa marque.
